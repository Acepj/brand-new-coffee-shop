
# ☕ D'Source House Cafe

**Freshly Brewed. Comfortably Served.**

D'Source House Cafe is a responsive coffee shop website designed to showcase coffee products, cafe services, customer testimonials, promotions, and reservation features. The website provides a cozy and modern user experience using Bootstrap 5, custom CSS, and Bootstrap Icons.

## 📌 Project Overview

This project is a front-end website for **D'Source House Cafe**, a neighborhood coffee shop located in Cabuyao City, Laguna.

It includes a visually appealing homepage, coffee menu, promotional section, reservation form, contact form, blog section, and customer testimonials.

## ✨ Features

- Responsive navigation bar
- Mobile-friendly menu using a checkbox toggle
- Hero section with coffee shop introduction
- About section with mission and vision
- Featured coffee menu
- Coffee product cards with prices
- Order modal for coffee items
- Coffee specials and promotions carousel
- Why Choose Us section
- Customer testimonials
- Image gallery
- Table reservation form
- Reservation confirmation modal
- Frequently Asked Questions (FAQ)
- Customer preference progress bars
- Coffee blog section
- Contact information and contact form
- Newsletter subscription form
- Social media links
- Responsive layout using Bootstrap Grid

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Custom styling and responsive design
- **Bootstrap 5.3.3** – Layout, components, and responsiveness
- **Bootstrap Icons 1.11.3** – Icons used throughout the website
- **Google Fonts** – Poppins and Inter
- **JavaScript** – Bootstrap interactive components and form functionality

## 🌐 Website Sections

### 1. Home

Introduces D'Source House Cafe with a hero banner, coffee shop tagline, and buttons for viewing the menu and reserving a table.

### 2. About

Displays the cafe's story, mission, and vision.

### 3. Menu

Shows featured coffee products, including:

- Spanish Latte – ₱165
- Cappuccino – ₱150
- Caramel Macchiato – ₱175
- Americano – ₱150
- Mocha – ₱185
- Cold Brew – ₱155

### 4. Specials

Features a Buy 1, Take 1 coffee promotion available every Monday.

### 5. Testimonials

Displays customer reviews and customer profile information.

### 6. Gallery

Shows images of the cafe, coffee beans, coffee products, and baristas.

### 7. Reservations

Allows users to enter their:

- Full Name
- Email
- Phone Number
- Number of Guests
- Reservation Date
- Reservation Time

### 8. FAQ

Provides answers about store hours and private event reservations.

### 9. Blog

Contains articles about:

- Coffee brewing tips
- Choosing coffee beans
- Cafe lifestyle

### 10. Contact

Displays the cafe's address, phone number, email, and business hours.

## 🚀 How to Run the Project

1. Download or clone this repository.

2. Open the project folder in Visual Studio Code.

3. Make sure the project contains the HTML, CSS, and image files.

4. Open `index.html` in your browser.

5. You can also use the **Live Server extension** in Visual Studio Code.

## ⚠️ Notes

- The reservation, contact, and newsletter forms require JavaScript or a backend system to process real submissions.
- The order buttons use Bootstrap modal attributes.
- Bootstrap's JavaScript bundle must be included for dropdowns, modals, accordions, carousels, and other interactive components to work.
- Some social media links currently use placeholder `#` URLs.
- The displayed cafe information is for website demonstration purposes.

### Bootstrap JavaScript

Add the following script before the closing `</body>` tag if Bootstrap interactive features are not working:

```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```
